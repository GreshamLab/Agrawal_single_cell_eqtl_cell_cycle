# Single-cell eQTL mapping in wild yeast strains across environments

Code for Agrawal et al.: pooled single-cell RNA-seq of 96 wild *Saccharomyces cerevisiae* strains,
demultiplexed with demuxlet, pseudobulked per strain and used for eQTL mapping (FaST-LMM) of SNPs,
InDels, SVs and gene-CNVs in six datasets: YPD (two replicates), fluconazole 16 and 8 ug/ml,
synthetic complete with glucose and synthetic complete with galactose.

This repository holds code only. Raw data, intermediate files, results and figures are not
included; the code reads them from absolute paths on the NYU HPC.

## Layout and order

| Folder | Content |
|---|---|
| `pipeline/` | Upstream steps: alignment, demultiplexing, FaST-LMM launchers (see `pipeline/README.md`) |
| `Figure.3/Fig.3_code_to_run_pseudobulk_and_fastlmm/` | Genotype preparation, pseudobulk and FaST-LMM eQTL mapping (steps 1-5) |
| `Figure.1/` | Strain table, demuxlet accuracy, scRNA-seq reproducibility, Figure 1 supplementary |
| `Figure.2/` | Differential expression between strains and clades, Figure 2 supplementary |
| `Figure.3/` | eQTLs in YPD.1: local and distant eQTLs, variant types, single-cell verification, YPD and fluconazole reproducibility |
| `Figure.4/` | eQTLs in the other five datasets (`Fig.4-<dataset>/`, generated by `generate_condition_rmds.py`), comparison between conditions and mashr (`Fig.4-PartII-compare-conditions/`); see `Figure.4/README_CURRENT_FILES.md` |
| `Figure.5/` | Cell-cycle phase and time per cell, harmonic models of cell-cycle expression, YPD.1 vs YPD.2 |
| `Supplementary_Tables/`, `publication_tables/` | Supplementary tables |
| `shared_code/` | Functions sourced by several figures (LD clumping and local/distant calls, fonts, Wilcoxon p-values) and render scripts |

Run order: `pipeline/` and `Figure.3/Fig.3_code_to_run_pseudobulk_and_fastlmm/` first, then
Figures 1-5, then `Supplementary_Tables/` and `publication_tables/`. Within a folder, files are
numbered or named by step (`Step1`, `Step2`, ...). Rmds are rendered with `rmarkdown::render()`;
the `*.sbatch` / `*.sh` files next to them are the Slurm jobs used to render them.

## Software

R 4.6.1 (Seurat, DESeq2, mashr, tidyverse, patchwork), Python 3, Cell Ranger, popscle
(demuxlet), PLINK 1.9 and FaST-LMM 0.6.12 (Singularity image).
